Mermaid Hotpaths

hover a source node = preview · click = pin · Esc / click empty space = clear
Paste any Mermaid chart. A node declares a trigger with @{ trigger: name, color: "#hex" } (or several: @{ triggers: ["a:#hex", "b:#hex"] }) and others listen with @{ listen: [name, ...] }. Edges between members light up on their own.
